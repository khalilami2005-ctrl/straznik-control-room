# Strażnik Control Room

Live prototype of **Strażnik**, an idea for the city of Rzeszów: a system that knows everything the city owns, checks every day that the city still holds it (even when it sits with suppliers), and warns before anything is lost.

All data is mock data. Supplier names are invented and the map is schematic.

## What it shows

- Key figures: assets tracked, share under city control, zero-copy assets, proofs of possession, urgent alerts, recorded know-how
- Schematic map of Rzeszów with 24 assets coloured by risk
- Asset identity card with loss score and actions (request delivery, sovereign copy, knowledge interview)
- Morning list ("the numbers"), proof-of-possession feed, sovereign vault, supplier health, knowledge capture, action log
- **Run demo: supplier failure**: a 30-second scenario from first warning signs to "nothing is lost"

## Run it

It is a single static file with no build step. Open `index.html` in a browser, or host the folder on any static host (GitHub Pages, Netlify, Vercel, nginx).
